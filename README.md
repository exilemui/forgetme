# forgetme

一个为 DeepSeek Harness 智能体打造的「人类遗忘式」记忆插件。

它不追求把一切都记住，而是**有节制地遗忘**——像人一样，把经历蒸馏成印象，随时间淡忘，最后彻底遗忘。同时，它保留「笔记本」，让真正刻骨铭心的东西长久留存。

---

## 设计哲学

人的记忆有两面：

- **遗忘是主旋律**：人对每件事的印象会随时间慢慢淡忘——先记得很多，然后只剩大概情节，再后来只剩一句话、几个词，最后彻底遗忘。遗忘不是缺陷，而是解决「脑存量有限」的好办法。对应到智能体，就是**上下文额度有上限**。
- **记忆与认知相互作用**：经历塑造认知；认知又像滤网，把每次客观事实加工成「印象/评价」。印象不是全貌，也不一定是真理，只是「我认为正确、值得记的事」。

forgetme 把这两点落到工程上：

1. **每个会话 = 一个记忆周期 = 一份记忆文件**，按时间顺序提取印象保存。
2. **遗忘 = 8 轮「印象加工」**（每次用 LLM 摘要式重写，而非机械截断），内容量逐轮递减，第 8 轮后彻底删除。
3. **笔记本**：自选若干词句长期保存，不参与遗忘，不贪心。
4. **唤起（召回）**：每次加工生成几个索引；新会话按索引做本地向量语义检索，命中就把旧印象 + 新体会写回当前记忆文件。
5. **反路径依赖**：召回的旧经验只作「参考」，不作教条——为了成长，为了不原地踏步。
6. **反上下文污染**：向量相似 ≠ 语境相关。召回分两层——先用本地向量检索召回候选，再用 LLM 做「相关度裁判」，过滤掉与当前意图「跑题」的旧记忆，避免把已完成的工作任务或无关闲聊强行扯进新对话。

## 遗忘模型

| 轮次 | 保留前一轮内容量 | 说明 |
|------|------------------|------|
| 第 1 轮（初加工） | 100% | 提取想记住的，哪怕细枝末节 |
| 第 2 轮 | ~85% | 丢掉更多细节 |
| 第 3 轮 | ~80% | |
| 第 4 轮 | ~70% | |
| 第 5~8 轮 | 各 ~60% | 逐轮压缩 |
| 第 8 轮后 | **彻底遗忘** | 删除记忆文件 |

触发方式：

- **手动**：随时调用 `decay` 工具拨动遗忘时钟。
- **自动（续命机制）**：当某会话上下文额度用完、被压缩重建（`agent/created` 的 `source === 'compact'`）时，自动对上一个会话做一次遗忘推进——在「死亡」前抢救蒸馏。

> 比例是「目标/上限」，不是硬截断：最后几轮如果信息量本就很少，会直接保留，不强行砍到 60%。

## 安装

### 方式一：本地目录（开发 / 试用）

1. 克隆本仓库到本地，在 DeepSeek Harness 里用 `plugin_manager` 的 `install_bundle` 安装本目录（本地目录安装是 **链接（link）**，不自动装依赖）。
2. 在本目录里手动装一次依赖：

   ```bash
   pnpm install --node-linker=hoisted
   ```

   这会把 `@xenova/transformers`（本地向量模型运行时）装进 `node_modules/`，并自动构建 `sharp`（`package.json` 里已声明 `pnpm.onlyBuiltDependencies: ["sharp"]`）。

3. 首次调用 `recall` 时，会联网下载一次 embedding 模型（约 118MB）并缓存到本地 `~/.forgetme/models/`，之后全程本地推理。

### 方式二：npm 发布版（后续）

发布到 npm 后，`plugin_manager install_bundle` 直接装包，依赖会自动安装，无需手动 `pnpm install`。

> 需要 Node 18+。

## 工具

| 工具 | 作用 |
|------|------|
| `remember` | 初加工：对当前会话写一份印象（可传 `text`，或自动 LLM 摘要） |
| `decay` | 拨动遗忘时钟：封存当前会话 + 推进所有旧记忆一轮 |
| `recall` | 唤起：按查询召回旧记忆（含相关度裁判过滤），命中写回当前会话记忆文件 |
| `notebook_add` | 写一条到笔记本（长期保存，不遗忘） |
| `memory_list` | 列出所有记忆（轮数/分类/预览）+ 笔记本 |

## 配置

所有字段都可在 DeepSeek Harness 的插件配置 UI 里修改（由 `Config` schema 提供）：

| 键 | 默认 | 说明 |
|----|------|------|
| `storeDir` | `~/.forgetme/rememberme` | 记忆存储目录（记忆数据属隐私，不进 Git） |
| `maxCycles` | `8` | 遗忘轮数上限，超过即删除 |
| `decayRatios` | `[0.85, 0.8, 0.7, 0.6, 0.6, 0.6, 0.6]` | 第 2~8 轮保留比例 |
| `categories` | `['工作','学习','聊天','情感','通用']` | 初步分类，按需增删 |
| `embedModel` | `Xenova/paraphrase-multilingual-MiniLM-L12-v2` | 本地向量模型（多语言，384 维） |
| `hfRemoteHost` | `https://hf-mirror.com` | 模型下载源（huggingface.co 被墙时走镜像） |
| `indexCount` | `4` | 每次加工生成的索引数上限 |
| `recallTopK` | `3` | 召回返回的最大旧记忆条数 |
| `recallMinScore` | `0.5` | 召回相似度阈值（0~1） |
| `recallJudge` | `true` | 相关度裁判：召回后加一道 LLM 判断过滤「跑题」候选 |

## 存储结构

```
~/.forgetme/
├── rememberme/
│   ├── index.json        # 遗忘时钟 + 所有记忆的索引（轮数/分类/时间）
│   ├── notebook.json     # 笔记本（长期保存，不遗忘）
│   └── memories/
│       └── <sessionId>.json   # 每会话一份记忆文件
└── models/               # 本地 embedding 模型缓存（首次召回时按需下载）
```

## 注意事项

- **sharp 原生库**：`@xenova/transformers` 依赖 `sharp`（仅用于图像模型，本插件只做文本嵌入不需要它）。pnpm 默认不跑构建脚本，但 `package.json` 已声明 `pnpm.onlyBuiltDependencies: ["sharp"]`，`pnpm install` 会自动构建 sharp。若 sharp 构建失败，文本召回会自动回退到字符 2-gram 重叠匹配（不会崩溃，只是语义精度下降）。
- **模型下载**：首次 `recall` 会联网下载 embedding 模型（约 118MB），之后缓存到本地 `~/.forgetme/models/`，全程本地推理，隐私不出本机。若 huggingface.co 不可达，会自动走 `hf-mirror.com` 镜像（可在配置里改 `hfRemoteHost`）。
- **推理模型预算**：摘要/索引/裁判用 `llm.stream` 时会自动把 `reasoningEffort` 降到模型宣传的最低档（排除 `off`），避免 DeepSeek 推理模型把整个 `maxTokens` 预算耗在思考上、产出空正文。
